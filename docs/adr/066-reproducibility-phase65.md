# ADR066 — kayıtlı lineage ve güvenli repro bundle, Faz65

2026-10-15 DEC65-01. Teknik kapsam deneysel; resmî kabul ayrı. Faz66 yetkisi yok.

Tek mevcut ProjectStore/Capability/experiment registry genişletilir; yeni kayıt sistemi yoktur. Graph mevcut source/dataset/operation/result kimliklerini kullanır. Dataset parent/input_version_ids, OperationSpec giriş/çıktıları, sonuç dataset_version_ids ve yeni report lineage_record_ids bağları kullanılır. Eski report'larda kaydedilmiş analysis/model kimliği yoksa yalnız dataset/source trace vardır; komşu sonucu rapora girmiş varsaymak yasaktır. WorkflowRun'un gerçek typed dependency ve train/model düğümleri aynı grafikte görünür. Hash/URI/schema/version, kayıtlı provenance, config/params, capture ve kararlar gösterilir; eksik code/backend/hardware/decision not_recorded kalır. Yeni RunCapture hardware kaydı capture sınırında yapılır; tarihî kayıtlar backfill edilmez. Bundle hardware.json bugünkü makinedir, eski run hardware'i değildir.

RowId küresel doğal anahtar değildir. Native identity sütunları snapshot'ta korunur. Multi-source join/append ve yeni satır aggregate/unpivot ilişkisi yalnız kaydedilmiş lineage Parquet varsa URI/hash ile görünür. Dataset düzeyinde graph bir satırın tüm kaynak ilişkisini yeniden kurmaz. Genel recursive row traversal mevcut değil. Bundle lineage graph bu kayıtlı relation referansını taşır; varsayılan relation satırları/veri bytes dahil edilmez.

Snapshot immutable native Parquet bytes kopyası, reference version/URI/hash/schema ile işaretleyicidir. Varsayılan repro bundle reference-only; kaynak erişimi için kullanıcı yerel projeyi açıkça seçer. Ağ/keyring/connector otomatik açılmaz. Data inclusion ayrı checkbox ve preview hash ile onaylanır; yalnız native snapshot'lar, en çok10000 satır/snapshot,32snapshot,128MiB bundle. Kişisel/veri değerleri ve RowId içerebilir. Secret adlı kolonlar ve bilinen secret örüntüleri reddedilir; kaynak düzeltilmez. Nested/binary kullanıcı verisi taraması desteklenmediğinden reference-only gerekir; native __vu_missing_fields List[String] metadata istisnadır. Tarama evrensel secret dedektörü değildir; paylaşım içeriği kullanıcı tarafından incelenmelidir.

Retain historical policy: mevcut quota/usage kullanılır; default4GiB artifact kotası ve ComputeBudget altında geçici iş. Otomatik GC/silme yok; archive disk boşaltmaz. Silme kalıcı snapshot/yeniden üretim kaybı yaratabilir; bu ekranda delete yoktur. Bundle128MiB/metadata8MiB/256member; büyüme önkontrolü ve temp disk/RSS/time/cancel uygulanır. İşler Qt'siz disposable worker; GUI worker parent tarafından doğrulanmış immutable state/manifest envelope ve pinned salt okunur artifact yolları alır, ProjectStore veya ACTIVE almaz. Bağımsız native resolver projeyi read-only açar. GUI receipt mevcut result journal'a eklenir, kullanıcı Projeyi kaydet ile kalıcılaştırır. Unsaved draft ile lineage/bundle oluşturulmaz; önce durable commit gerekir.

Bundle manifest, config, lineage, reference-report aggregate, env lock, requirements.lock, hardware, storage policy, redaction preview, README ve optional data taşır. Arbitrary executable/model pickle/import yoktur. Güvenli model artifact ilk kapsamı workflow OLS katsayıları ve tasarım tarifi üzerinden karşılaştırma reference'ıdır; bağımsız her model ailesini yeniden fit/reuse destekli göstermez. Genel model persistence başka kayıtlı registry yeteneğidir. Config/aggregate sonuçların kendisi de hassas olabilir. Dış path/URL, secret key/value örüntüleri ve name/note/title/description gibi serbest metin alanları redakte edilir; preview yalnız alan konumu/neden içerir, orijinal değer göstermez. Config/reference redakte olduysa re-run unsupported; temizlenmiş parametreyle eşdeğer sonuç iddiası yoktur. Credential/env değerleri/keyring okunmaz. Hashler bozulma kontrolüdür; manifest'i yeniden imzalayan saldırgana karşı authenticity garantisi değildir. Hash bilgisi veri erişim hakkı sağlamaz.

Bundle açma hiçbir kod çalıştırmaz; ZIP duplicate/path traversal/symlink/encryption/size/closed-member/schema/method sürümü ve tüm member SHA256/size doğrulanır. JSON duplicate key/nonfinite reddedilir; ZIP extractall yoktur. Re-run ayrı açık eylem: tam Python/package/core closure/workflow backend/code/platform lock eşleşir. Farklı schema/method/backend için otomatik migration yok; safe failure ve orijinal dosyanın korunması esastır. Farklı platform/GPU doğrulaması yoktur. Seed tek başına determinism değildir; requirements.lock bir offline installer/wheelhouse değildir. Yerel CPU kontrollü koşu kanıtı temiz offline kurulum yerine geçmez.

Gerçek verifier adapter'ları: (1) kaydedilmiş numeric measurement dataset profile, filtresiz tam veri veya mevcut firstN≤10000; (2) tamamlanmış Faz64 bounded workflow'un tanımlı analytical projection'ı. Bir raporda tam bir destekli analysis/run kimliği kaydedilmişse o reference karşılaştırılır; HTML/PDF layout/render byte eşdeğerliği iddia edilmez. Diğer analiz/model yöntemleri için lineage/integrity vardır, re-run unavailable açık gösterilir. Workflow re-run saf hesap/cache/export hazırlığını özel temp'te yapar; dış export düğümleri parent publish edilmez, kaynak/run çıktıları değişmez. Sonuç comparison/reference-report/actual-report içeren yeni exclusive .vureprotest artifact'tır. Final test erişimi veya evaluation yapılmaz.

Exact policy: tanımlı analytical projection typed değerleri exact; rastgele run UUID/timestamp/cache/path/plot layout karşılaştırma dışıdır. RowId/SourceRecordId/ColumnId, count, kategori ve null mask exact. Profile Decimal precision80 ve onun numeric string çıktıları exact; bütün sayısallara epsilon uygulanmaz. Numeric policy ilk kapsamı yalnız bounded OLS Float64 coefficients/predictions: |new-ref|≤max(1e-12,1e-9×max(|new|,|ref|)). Absolute tolerance çıktı birimindedir; küçük CPU fixture'da FP/matrix yuvarlama payını denetler, kötü conditioning/başka ölçek/başka dtype için evrensel eşdeğerlik değildir. Policy ve gerekçe her comparison artifact'ta; count veya identity farkı toleransla kabul edilmez. Veri snapshot hash farkı numeric tolerance'tan önce re-run'ı durdurur. Reference/new hashler ve en çok50 ihlal örneği, toplam fark sayısı ile saklanır. Fark bulunması hata gizleme değildir; status=different.

GUI yolu Rapor → Lineage ve bilimsel yeniden üretim; focus, source graph, node ayrıntısı, redaction/data inclusion preview, bundle create, bundle open/hash ve explicit re-run. Offline yardım lineage/snapshot/environment/tolerance/araştırma kaydı. Network ve model download gerekmez. Fiziksel/human/AT/minimum donanım/uzun retained heap/clean offline installation/remoteCI ayrı resmî açık kalır.

Faz65 bellek düzeltmesi: ortak Linux RSS probe jobs/resources.py içine taşındı; Control.check job registry/model runtime import etmez. Workflow code/env fingerprint de backend import etmeden installed source dosyalarını hash eder. Cache key artık göreli tam code path kullanır; değişen fingerprint eski key güncel sayılmaz. Eski kayıtlar değişmez; eski workflow signature farklıysa re-run safe failure verir. Bu değişiklik resource bütçesini artırmaz veya önceki uzun retained-heap kabulünü kapatmaz.
