# ADR-009 — yapılandırılmış import ve native türler

2026-10-06; Faz06; deneysel. Python/PySide6/QML korunur. Yeni bağımlılık yok; CSV/TSV adaptörleri mevcut ortak worker/yayın protokolüne bağlı kalır. [ADR-008](008-delimited-import-phase05.md), [CORE_CONTRACTS](../CORE_CONTRACTS.md).

`SourceAdapter` sınırı validate_source/inspect/preview/import_data; registry csv/tsv/json/jsonl/xlsx/parquet. Dosya uzantısı yalnız ipucu; magic, JSON parser, OOXML ilişkileri ve Parquet metadata doğrulaması kullanılır. Hatalı yakalama sonrası özel kopya korunur, kullanıcı format/yol/ayar düzeltip yeniden önizler. Önizleme en fazla200 kaynak kaydı ve200 gösterilen çıktı; tam import bütün alanların birleşimini ve türleri yeniden inceler. JSON anahtar sırası kullanılmaz. Kullanıcı sütun türlerini seçmişse tam alan listesi önizlemeden farklı olduğunda indeksler yeniden eşlenmez; kullanıcı türleri sıfırlamalıdır.

JSON UTF-8/BOM, kök kayıt listesi veya RFC6901 JSON Pointer; JSONL/NDJSON her fiziksel satır ayrı kayıt. Duplicate key ve NaN/Infinity yasak, boş/bozuk JSONL karantinaya numara/locator/raw/reason ile gider. `json.loads(parse_float=Decimal)` sayıları float ara dönüşümü olmadan okur ([Python JSON](https://docs.python.org/3/library/json.html)). Int64 dışı integer Decimal kapasitesi≤38 ise kesin korunur; numeric int/Decimal ortak kesin ölçekle birleşir. Eksik alan, açık null ve gözlenen türler recursive raporda ayrıdır. Nested struct/list korunur. Karışık tür, >38 hane ve boş struct native Parquet sınırında varsayılan reject; açık `json_text` exact kanonik JSON metni seçilebilir. Bu durumda string değeri de JSON tırnaklarıyla saklanır; sayı1 ve string"1" ayırt edilir. String kimlik ve başındaki sıfır değişmez. Kullanıcı Float64 seçerse önizlemede yaklaşık ikili sayı uyarısı; 2^53 üzeri integer, overflow/underflow mevcut CSV convert sınırında reddedilir. Decimal kullanıcı seçimi kesin Decimal(38,6), yuvarlama yok.

Düzleştirme yalnız dict alanlarına uygulanır: /adres/il gibi escaped yol, liste açmaz. Liste açma ayrı `expand_lists` seçimi; bağımsız listeler Cartesian product oluşturur. Önizleme kaynak/çıktı sayısı ve en büyük tek kayıt artışını gösterir. Boş/null liste bir dış satır, eksik liste alanı eksik kalır. En fazla8 bağımsız yol ve tek kaynak kaydından100000 çıktı; ancestor/descendant birlikte veya ara listeden geçen path reddedilir. Her çıktının RowId'si farklı, aynı kaynak kaydının çıktıları aynı SourceRecordId; expansion koordinatları/locator/missing alan listesi ayrı lineage kolonlarında. Bu Faz06 import seçimi; genel Faz09 dönüşüm motoru değildir.

XLSX için bounded stdlib ZIP/XML OOXML okuyucusu seçildi: makro/formül çalıştırmadan, sayısal XML değerini Python float'a dönüştürmeden Decimal/int okuyabilir. ZIP extract edilmez; dış ilişki takip edilmez. Mutlak/../backslash/symlink/duplicate arşiv üyeleri, encryption, DTD/entity, macroEnabled/vbaProject ve aşırı parça/boyut reddedilir. Sayfa, fiziksel başlık satırı (0 başlıksız), A1:D100 range. Birleşik hücre default reject; anchor yalnız sol üst, kalan hücreler null, değer yayılmaz. Boş satırlar keep veya açık skip. Orijinal boş/tekrarlı başlıklar metadata'da korunur. `formula` =formül, `text` = olmadan metin, `cached` yalnız mevcut v değeri; eksik cache hata/karantina, shared formula metni çözülemiyorsa destek sınırı. Önbellek güncelliği garanti edilmez; Excel'in önceden kaybettiği rakam üretilmez. [SpreadsheetML](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/overview), [CellValue/cache](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.cellvalue).

Excel date1904 workbookPr kontrolü; [1900/1904 tarih sistemleri](https://support.microsoft.com/en-us/excel/date-systems-in-excel) 1462 gün farkıdır. Excel1900 seri60 sahte1900-02-29 reddedilir; seri>60 bir gün düzeltilir. Stil tarihse Decimal seri us'a **tam** çevrilir; sub-us kesir reddedilir, serial seçeneği asıl sayıyı saklar. Elapsed süre formatı, desteklenmeyen shared formül veya timezone içeren ISO hücre açık sınırdır. Excel tarih varsayılan naive Datetime(us); UTC varsayılmaz. Açık sütun datetime dönüşümü strptime+IANA/DST ortak convert kurallarına bağlıdır.

Parquet native Int/UInt widths, nullable/Null, Decimal≤38, Float/NaN/Inf, Binary, Date/Time, Datetime(ms/us/ns + zone), List/Struct korunur. Lazy scan→native map_batches kimlik→streaming sink; özgün kolonlar Python skalarına çevrilmez. Önizleme temporal Rust string kullanır; ns değeri Python datetime yolunda kırpılmaz. Duration/Array/Categorical/Enum/Object türleri açık destek sınırıdır. Parquet veri saklama capability'si ortak analitik us normalizasyonundan ayrıdır: kaynak ns aynen tutulur, sonraki analitik için ns→us ancak ayrı kayıp kontrollü işlem olabilir. [Polars türleri](https://docs.pola.rs/user-guide/concepts/data-types-and-structures/), [read_parquet_schema](https://docs.pola.rs/docs/python/dev/reference/api/polars.read_parquet_schema.html).

JSON tek belge≤64MiB tam parse; XLSX XML parçası≤64MiB, toplam açılmış içerik≤min(256MiB,temp budget),≤10000 üye; bu iki adaptörde streaming iddiası yok. JSONL1MiB satır,256 alan, nesteddepth16/toplam4096 type node; full profiling + ikinci dönüştürme geçişi. Kayıt4096/8MiB chunk ve16384 part; kaynak≤1GiB/quarter-temp-budget ve ortak ComputeBudget/cancel/time/resource limit. Native sink cooperative check yoksa parent grace sonrası süreci öldürür. Toplam peak RAM/disk hard quota veya minimum donanım garantisi değildir.

Yayın: worker geçici artifact→parent kopya/hash/şema/sayım→kalıcı artifact→SQLite commit→manifest→ACTIVE; önceki sağlam kayıt korunur. Şema3 uygulama0.1.0'dan bağımsız; native_schema yalnız JSON veri descriptor'larıdır, eval/pickle yok. Manifest0 readonly/save-as→3;1/2 açılışta değiştirilmez, açık kayıt→3/migration. Settings, original fields, diagnostics/full, fingerprint, SourceSnapshotId ve shared Provenance saklanır. Önizleme ve import aynı özel doğrulanmış snapshot; orijinal değişirse açık eski snapshot politikası, değişmiş kaynak güncel kabul edilmez.
