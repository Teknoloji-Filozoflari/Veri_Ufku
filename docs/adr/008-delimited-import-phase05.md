# ADR-008 — CSV/TSV, değişmez kaynak ve tamamlanmış dataset yayını

2026-10-06; Faz05; kabul edilen uygulama kararı. Faz06+ format/analiz motoru uygulanmaz. [ADR-003](003-storage-publication-lock.md) ve [ADR-007](007-project-store-phase04.md) ilkelerini kullanır.

Python `csv.reader`, `newline=""`, strict encoding/CSV ve açık ayarlarla tek ortak preview/import ayrıştırıcısıdır. CSV Sniffer ayraç/başlık, encoding denemesi encoding önerir; garanti değildir. Başlık mantıksal CSV kaydıdır; 0 başlıksızdır. Boş/tekrar/rezerve başlıklar benzersiz adlandırılır, özgün başlık saklanır. Boş fiziksel kayıt sessiz atılmaz. Açık kalan tırnak EOF'a kadar tek bozuk aralıktır; belirsiz içerideki satırlar uydurulmuş kayıtlar olarak kurtarılmaz. [Python CSV](https://docs.python.org/3/library/csv.html) birincil kaynak olarak incelendi; özellikle newline, string varsayılanı ve Sniffer'ın sezgisel olması kullanıldı.

Varsayılan tüm türler metin; öneriler en fazla 200 incelenen kayıttan gelir. Aynı ImportSettings tam okumada aynen uygulanır. Int64 sınırı/kesir, leading-zero dönüşümü, Float64 uzun integral/sonsuz/underflow, Decimal(38,6) hassasiyet ve belirsiz/nonexistent DST reddedilir. Float64 kullanıcı seçimi ikili yaklaşık sayıdır; Decimal kesin ölçek sınırını aşınca yuvarlanmaz. Empty string varsayılan null değildir; açık null işaretleri metin dahil bütün türlerde uygulanır. Tarih Python strptime biçimiyle yorumlanır; naive saat UTC varsayılmaz, IANA timezone açık seçilir. date yalnız tarih tutar.

Kaynak tam olarak özel geçici dizine kopyalanır. İki okumanın SHA256/boyut ve inode/mtime/ctime kimliği uyuşmadan kopya kabul edilmez. Önizleme ve import aynı yakalanmış kopyayı kullanır; kopya okumadan önce ve sonra hash doğrulaması alır. Kaynak dışarıda değişirse ekrandaki açık kopya-zaman/fingerprint politikası nedeniyle eski kopyadan içe alınır; güncel kaynağı almak için yeniden dosya seçilir. Proje kaynak durumu changed olur. Dış kaynak hiçbir zaman yazılmaz. Bu, aktif düşmanca yazarı kilitleyen OS snapshot API'si değildir; kaynak yakalama sırasında değişim reddi ve sonrasında özel kopyadan işlem politikasıdır.

Her tam import yeni SourceSnapshotId, her veri kaydı ayrı SourceRecordId, kabul edilen kayıt ayrıca RowId UUIDv4 alır. Aynı içerikli kayıtlar ayrı kalır. Fiziksel başlangıç/bitiş satırı locator'dır, kimlik değildir; çok satırlı hücreler dahil saklanır. ColumnId metadata'da ayrı UUIDv4. Row/SourceRecord kimlik haritası dataset Parquet'tedir; karantina kendi SourceRecordId/ordinal/satır aralığı/raw/reason kolonlarını taşır. Kopyalama/yeniden açma kimlikleri korur, yeni import yeniden kimlik üretir. Join/explode/aggregate/dedup sonraki fazlardır.

CSV işi spawn sürecinde; Qt nesnesi veya proje yazıcı kilidi geçmez. Aynı ComputeBudget/Capability/Provenance sözleşmeleri kullanılır; input ayarları iş süresince sabitlenir ve config_revision provenance'a girer. Kontroller: cancel/time sınırları, CPU affinity/CPU rlimit, başlangıç address-space üzerine RAM tahsis sınırı, source/disk/record/column sınırları. RAM rlimit tek başına toplam parent+worker RSS garantisi değildir; gerçek RSS örneklemesi ayrıca kaydedilir. Bir importer süreci aktif olabilir. Altyapı demo manager'ı ayrı kalır; eşzamanlı demo+import toplam donanım kabulü ölçülmedi. Kaynak en fazla 1 GiB ve temp bütçesinin dörtte biri; 256 sütun; kayıt 1 MiB; chunk4096 kayıt veya8 MiB raw; en fazla16384 parça. Polars lazy scan + streaming sink ile Parquet birleştirilir; tam DataFrame belleğe alınmaz. [Polars sink_parquet](https://docs.pola.rs/api/python/stable/reference/api/polars.LazyFrame.sink_parquet.html) birincil kaynak olarak incelendi; gerçek locked2.0.0 yolu fixture'larla çalıştırıldı. Sink sırasında cooperative check yoksa parent grace sonunda süreci sonlandırır. Chunk sınırları/sonunda disk kontrolü vardır; toplam sistem diski veya native sink'in anlık peak için hard quota iddiası yok.

Worker yalnız geçici dosyalar üretir. Parent proje I/O executor'ı çıktıları ayrı staging'e kopyalar, hash/satır/şema doğrular; ardından mevcut artifact→SQLite→manifest→ACTIVE protokolüyle tek kayıtta yayımlar. Karantina snapshots/*.parquet artifact'ıdır. Dataset descriptor'ın import_metadata/quarantine_uri alanları bağımsız proje şema2 ile geldi; uygulama sürümü0.1.0 kalır. Şema1 metadata değişmeden açılır; sonraki açık manuel kayıt veya import yayını şema2 ve migration kaydı üretir, eski immutable commit korunur. Salt okunur şema1 açılışı migrasyon yazmaz. Şema0 readonly açılır ve Farklı kaydet ile şema2 kopyaya geçer. Şema1 fixture ve aç/kaydet migrasyon testi vardır; gelecekteki şema reddedilir.

İptal publication'ın ACTIVE değişimine kadar geçerlidir; o sınırdan sonra tamamlanmış kaydın sonradan geri alınması yoktur. İçe aktar ve projeye kaydet mevcut draft değişikliklerini de kaydeder; UI açıklar. Proje geçişleri/kayıt/autosave/kapanış importer aktifken engellenir. Önceki manuel ACTIVE başarısız parser/cancel/pre-publication adımlarında aynı kalır. ACTIVE sonrası dayanıklılık hatasında açılışın state'i uzlaştırılır; eski state sessizce üstüne yazılmaz. İkinci yazıcı mevcut kernel kilidi nedeniyle readonly; import reddedilir. Ağ FS desteği eklenmez.

Geçici Parquet parçaları tekrar import öncesi yalnız importer'ın özel dizininden temizlenir; proje artifact'ları hard-link edilmez, kopyalanır. Normal shutdown özel dizini kaldırır. Sert uygulama ölümünden kalan cache dizinlerini kör silen global temizleyici yoktur; proje staging eski kayıtları koruyarak karantinaya taşır. Karantina raw kişisel veri içerebilir; yerel proje snapshot'ı olarak saklandığı UI'de açıklanır, log'a yazılmaz. [Gerçek kontroller](../evidence/PHASE05.md).
